## Menjalankan Program

Pastikan Python sudah terinstal, kemudian jalankan melalui terminal:

```bash
python3 main.py
```

Untuk menjalankan program soal tertentu:

```bash
python3 soal_1.py
```

Ganti `soal_1.py` dengan file soal lainnya sesuai kebutuhan.
